# app-index-journal

一个用于归档和发布多个独立 HTML 页面的仓库。

## 项目简介

本仓库主要用于收集、组织并托管一系列独立的 HTML 页面。这些页面各自独立，不依赖特定后端服务，适合作为静态内容存档、轻量级工具页面、演示页面或临时页面的存放地。

## 目录结构

```
.
├── pages/            # 存放所有独立 HTML 页面文件
│   ├── example1.html
│   ├── example2.html
│   └── ...
├── assets/           # 页面共用的资源文件（CSS、图片、字体等，可选）
├── index.html        # 仓库根目录下的索引页（如有）
└── README.md         # 本文件
```

- `pages/`：每个 HTML 文件为一个独立页面，可直接通过浏览器访问。
- `assets/`：如果多个页面需要共享样式或资源，可放置于此目录下。
- `index.html`：可选的首页或导航页，用于展示所有页面的链接。

## 页面归档说明

- 所有页面均为纯前端实现，无服务器端依赖。
- 每个页面应自包含其功能所需的内容，尽量不依赖外部资源，如需使用外部库建议注明来源。
- 页面之间相互独立，删除或修改某个页面不会影响其他页面。

## 维护说明

- 新增页面：在 `pages/` 目录下创建新的 `.html` 文件即可。
- 更新页面：直接编辑对应文件，修改后提交到仓库。
- 删除页面：移除对应文件，并更新索引页（如有）。
- 建议为每个页面添加简单的注释说明其用途。

## 使用方式

1. 克隆本仓库到本地。
2. 直接在浏览器中打开 `pages/` 下的任意 HTML 文件。
3. 或通过 GitHub Pages 等服务部署后访问。
